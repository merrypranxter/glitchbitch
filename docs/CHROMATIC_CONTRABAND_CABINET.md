## Current Glitchbitch coverage (avoid duplication)
`src/materials.js` already has three-wavelength prismatic foil, thin-film and opal responses; `src/appearance.js` has 4x4 Bayer quantization, CMY Riso, CRT phosphor, glitter; `src/renderer.js` has RGB split and memory effects. `src/photon-zoo.js` and `src/substance.js` add optical and biological materials. A new palette name, renamed thin film, or ordinary CMY Lithogenesis would not add meaningful art.

## Source-backed candidates, ranked by genuinely new behavior

1. **OKLab Chroma Oracle — PRIORITY A.** [THISWEIRDGREENONEHERE](https://github.com/merrypranxter/shaderslop_designs/blob/main/by_math/13_optics_spectral_color_science/THISWEIRDGREENONEHERE_20260630_144045.js) implements `oklab_to_srgb` and a candy-acid spectrum. Add perceptual-lightness-preserving chroma rotations, warped hue bands, and color-space exaggeration that follow the current field. NOT the existing HSV palette shift.
2. **Birefringent Cellophane — PRIORITY A.** [Chimeric Prism Cathedral](https://github.com/merrypranxter/shaderslop_designs/blob/main/by_math/13_optics_spectral_color_science/chimeric-prism-cathedral_20260624_204630.js) exposes `u_biref` and perceptual/spectral math; [Chromatic Reef Surge](https://github.com/merrypranxter/shaderslop_designs/blob/main/by_math/13_optics_spectral_color_science/chromatic-reef-surge_20260624_211707.js) constructs a birefringent Voronoi cellophane motif. Port the directional two-phase color response **without** the source's entire 3D/float feedback architecture.
3. **Chromadepth Riso — PRIORITY A.** [Chromadepth Riso](https://github.com/merrypranxter/shaderslop_designs/blob/main/by_math/14_visual_perception_stereograms_phosphenes/chromadepth_riso_20260623_115743.js) contains moving density fields and rotated halftone ink dot gain; [Jewel Phosphene](https://github.com/merrypranxter/shaderslop_designs/blob/main/by_math/14_visual_perception_stereograms_phosphenes/jewel_phosphene_20260629_194920.js) explicitly maps perceptual near pink/red to far cyan/blue. Couple *apparent color depth* to animated printing (not another fixed CMY screen).
4. **Phosphene Gem / Soft-White Crown — PRIORITY A.** [Jewel Phosphene](https://github.com/merrypranxter/shaderslop_designs/blob/main/by_math/14_visual_perception_stereograms_phosphenes/jewel_phosphene_20260629_194920.js) also contains complex-plane math and breathing radial glow. Adapt living white/puffy highlights and fringe chroma to arbitrary math fields without covering the whole canvas.
5. **Rainbow XOR / Temporal Dither — PRIORITY B.** [Rainblow Ditherscape](https://github.com/merrypranxter/shaderslop_designs/blob/main/by_math/16_dithering_halftone_print/rainblow-ditherscape.js) has exact Bayer 4x4 thresholds, time-driven XOR coordinate patterns and wavelength-based thin-film phases. Unlike current fixed dithering, *pixel decisions move*. Original GLSL uses bitwise integer operators; rewrite for WebGL1 or require WebGL2 explicitly.
6. **Hypercolor Damage Reactor — PRIORITY B.** [Hypercolor Damage Carnival](https://github.com/merrypranxter/shaderslop_designs/blob/main/by_math/15_signal_processing_vhs_crt_glitch/hypercolor_damage_carnival_engine_20260619_111904.js) defines RGB/HSV transformations, caustic flow, halftone geometry and feedback. First port only analytic color-space injury and moving caustic dot breakup; protect the existing Signal Break and VHS modes from duplication.
7. **CMY Bragg Eruption — EXTRACT, DON'T DUPLICATE.** [CMY Substance](https://github.com/merrypranxter/shaderslop_designs/blob/main/by_math/16_dithering_halftone_print/cmy-substance_20260709_104234.js) has a time-morphing Minkowski distance metric, agate warp and CMY interference. Existing Substance already uses its lithogenesis family; only spin off a globally applicable **field-driven color contour** if it adds unique controls.
8. **Spectral Desynchronization — DEFER HEAVY PATH.** [Spectral Desync](https://github.com/merrypranxter/shaderslop_designs/blob/main/by_math/13_optics_spectral_color_science/spectral_desync_20260630_115002.js) uses Gaussian RGB spectral responses, 70-step raymarching and `sampler2D u_prev` feedback. Distinct idea: red/green/blue retain *different temporal histories*. Prototype through existing Frame Memory before considering a second framebuffer.
9. **True sampled dispersion — DEFER FULL VERSION.** [THISWEIRDGREENONEHERE](https://github.com/merrypranxter/shaderslop_designs/blob/main/by_math/13_optics_spectral_color_science/THISWEIRDGREENONEHERE_20260630_144045.js) uses **16 wavelength samples and Cauchy refraction**. Valuable math, but port a bounded 3/5-band approximation first; don't paste a 16-ray raymarch into Safari.
10. **Advected color-ghost ribbons — DEFER FEEDBACK.** [Neon Serpent Interference](https://github.com/merrypranxter/shaderslop_designs/blob/main/by_math/08_waves_interference_moire_cymatics/neon_serpent_interference_20260625_142516.js) advects a previous-frame texture. Interesting spectral trails but needs explicit memory and export replay controls.

## Implementation program

**Wave A: Color Sorcery** — new `src/chromatic-alchemy.js` containing four independent opt-in, single-pass engines (OKLab Chroma Oracle, Birefringent Cellophane, Chromadepth Riso, Phosphene Gem). Controls: mode, presence, spectral separation, field scale, softness/white crown, motion, variation, **Use my palette (on by default)**, targeted shuffle and presets. Place under Effects → Light. No new framebuffer or 16-sample raymarch, no extra time loop. Compiled shader branch is keyed to mode and omitted when presence is 0. Existing text compositor remains separate and untouched.

**Wave B: Print/Spectrum Injury** — Temporal XOR Dither, Caustic Dot Gain, HSV Damage Reactor. These must have distinct *pixel/color dynamics* rather than new preset names.

**Wave C: Temporal Spectral Memory** — separately opt-in chroma-channel feedback and true dispersion; capped per-device memory, no silent fallback to WebM.

**Hard gate for every wave:** preserve old shader IDs and saved recipes; PNG/GIF/MP4 share the same timeline; 9:16 and 1:1; deterministic shuffles don't overwrite art/palette/text; branch pruning and cache keys; Undo; mobile pinned canvas; **run `npm run verify`** (tests + Vite build) in a connected development environment, then render iPhone Safari PNG, 2–3s GIF and MP4 at matching timestamps. Source checks alone do NOT certify Safari or export parity. No automatic Netlify deploy.
